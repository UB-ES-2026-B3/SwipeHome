# SwipeHome
Somos 6 jóvenes con un sueño: hacer que el alquiler de pisos sea una experiencia agradable. Por ello, con esta aplicación podrás disponer de miles de pisos a tu alcance y con solo un movimiento decidir si te gusta o no; nunca antes alquilar había sido tan fácil.

## Pruebas

La [guía de testing](docs/TESTING.md) explica cómo preparar los emuladores y

historia en la [matriz de cobertura](docs/TEST-COVERAGE.md).
